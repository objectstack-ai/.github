<p align="center"><b>The ontology is the software.</b> &nbsp;·&nbsp; 本体即软件</p>

<p align="center">One executable business ontology. AI writes it, the runtime runs it, agents operate it, you own it.</p>

Your app is a **business ontology** — objects, relations, actions, permissions, flows,
agent and tool definitions — typed, validated, versioned in your repository, and small
enough for an agent to hold whole. The runtime derives the database, REST API, Console
and MCP tools from that one definition, and enforces permissions and audit on every call.

**ObjectOS** is the product that runs it, in three editions:
**Community** (open source, self-hosted, free — the code is in [objectstack](https://github.com/objectstack-ai/objectstack)),
**Cloud** (we operate it) and **Enterprise** (your infrastructure, licensed).
**ObjectStack** is the open protocol, SDK and CLI the ontology is written in — Apache-2.0,
so the ontology moves between editions as a file in your repository.

- 🛠️ **Build with your coding agent** — `npm create objectstack@latest`, then open the project in Claude Code and describe what the business needs. [Framework docs →](https://objectstack.ai/docs)
- ☁️ **Build & ask online** — nothing to install. [objectos.ai →](https://www.objectos.ai)
- 🐛 **Found a problem in any edition?** [Open an issue in objectstack](https://github.com/objectstack-ai/objectstack/issues) — the one public tracker.
